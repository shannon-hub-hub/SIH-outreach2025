Overview: 
Migrated data from Google Sheets into PostgreSQL.
Designed a relational database with three tables: students, events, and outreach_campaigns.
Performed analytics on campaign effectiveness, cohort engagement, and conversion performance using SQL features like joins, CTEs, aggregations, and window functions.

Key Analyses: 
Conversion Rates by Strategy
Calculated overall conversions vs. interactions for each outreach strategy.
Highlighted top-performing strategies and underperforming approaches.
Cohort-Level Engagement
Measured engagement per student cohort across campaigns.
Identified cohorts with the highest conversion rates, revealing insights for targeted outreach.

Impact: 

Enables data-driven decision-making for outreach campaigns.
Helps identify which strategies and cohorts yield the best engagement.
Can be scaled to larger datasets to simulate real-world analytics scenarios.
